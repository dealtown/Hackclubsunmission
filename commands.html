Useful CMD Commands

Jump to Advanced Commands ↓

1. DIR

The DIR command displays files and folders inside the current directory.

2. CD

The CD command allows you to move between folders in Command Prompt.

3. CLS

The CLS command clears the text currently displayed in the Command Prompt window.

Basic Command List

  • DIR — List files and folders
  • CD — Change directory
  • CLS — Clear the screen
  • MKDIR — Create a folder
  • DEL — Delete a file
  • IPCONFIG — View network information
  • start (file location) — Runs that file

Advanced Commands

Once you understand the basics, you can investigate commands such as ipconfig, ping and tasklist also if you want mkdir

Be careful with commands that modify or delete files.
